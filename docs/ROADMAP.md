# Roadmap

1. **MVP local** : projets, GeoJSON, carte, sélection et superficies, responsive, À propos, documentation.
2. **Backend** : Supabase/PostGIS, authentification, profils et sécurisation RLS.
3. **Imports départementaux** : ingestion Etalab/EDIGÉO via VPS, index spatiaux, millésimes, supervision.
4. **Fonctions avancées** : cadastre/orthophoto IGN, exports, recherche cadastrale, partages, PWA.
